## ScreenBar - QR and Barcode Scanner

**Зависимости**
+ RPM: `gtk2`, `zbar`, `scrot` (Mageia 10)
+ DEB: `libgtk2.0-0`, `zbar-tools`, `scrot` (Ubuntu)

**Рабочий каталог:** `~/.config/screenbar`
![](https://github.com/AKotov-dev/ScreenBar/blob/main/Screenshot2.png)  
Программа предназначена для быстрого сканирования QR- и бар-кодов,
отображаемых на экране монитора, без использования веб-камеры.

Основное условие успешного сканирования — полная видимость кода:
он не должен быть перекрыт другими окнами или элементами интерфейса.

При запуске сканирования программа делает снимок экрана и передаёт
полученное изображение утилите `zbarimg`, которая пытается распознать
один или несколько QR- или бар-кодов.

Распознанные данные преобразуются в текст. Полученный текст автоматически
копируется в буфер обмена; также его можно сохранить в файл.

Снятием скриншотов в различных DE занимаются нативные утилиты
либо, в случае X11, универсальная утилита `scrot`:

```text
XDG_CURRENT_DESKTOP
        │
        ├── Budgie   (X11)  → scrot
        ├── GNOME           → gnome-screenshot
        ├── KDE             → spectacle
        ├── XFCE            → xfce4-screenshooter
        ├── LXQt     (X11)  → scrot
        ├── LXDE     (X11)  → scrot
        ├── MATE     (X11)  → scrot
        └── Cinnamon (X11)  → scrot
```
Финальное распознавание кодов выполняется утилитой `zbarimg`.
